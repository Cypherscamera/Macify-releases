# Macify-releases
Installer and update files for Macify

## Download (Windows)

**[⬇ Download Macify-win-Setup.exe](https://github.com/Cypherscamera/Macify-releases/releases/latest/download/Macify-win-Setup.exe)**

Run the file and Macify installs itself. Future updates install automatically.

If Windows SmartScreen warns, click **More info → Run anyway**.

Prefer no installer? [Download the portable zip](https://github.com/Cypherscamera/Macify-releases/releases/latest/download/Macify-win-Portable.zip), unzip, run the app inside.

The other files on the [Releases page](https://github.com/Cypherscamera/Macify-releases/releases/latest) (`.nupkg`, `RELEASES`, `releases.win.json`) are update files used by the app. You do not need them.
