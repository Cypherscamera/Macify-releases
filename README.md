# Macify: Mac keyboard shortcuts, Spotlight, Dock and dictation for Windows

**Macify is a Windows app that makes a Windows laptop feel like a Mac.** It turns your keyboard and touchpad into a Mac's: ⌘ shortcuts, ⌘Tab app switching, Spotlight search, Quick Look, window tiling, a Dock, a menu bar, hot corners, a Control Center, private offline voice dictation and everyday file tools. It runs from the system tray and needs no administrator rights.

## What Macify does

| Feature | What you get on Windows |
|---|---|
| **Mac keyboard shortcuts** | Alt acts as ⌘ Command, the Windows key as ⌥ Option, Ctrl as ⌃ Control. ⌘C, ⌘V, ⌘T, ⌘W, ⌘Q and the rest work the way they do on a Mac. |
| **⌘Tab app switcher** | One icon per app, like macOS, with ⌘` to cycle the windows of the current app. |
| **Spotlight search (⌘Space)** | Find apps and files, do quick calculations and search the web from one box. |
| **Quick Look** | Press Space on a file in File Explorer for an instant preview. |
| **Window tiling** | Rectangle-style shortcuts for halves, quarters, thirds, fill, center and moving between displays. |
| **Dock, menu bar and hot corners** | A Mac-style Dock and menu bar for Windows, plus screen-corner actions. |
| **Control Center** | Wi-Fi, Bluetooth, sound, dark mode and more in one panel. |
| **Dictation (⌃⌥M)** | Speak and your words are typed at the cursor as you say them, in any app. Press the shortcut to start and again to finish. It runs on your PC with no internet connection, so your voice stays private. |
| **File tools** | Convert, compress and resize images (HEIC, WebP, AVIF, PNG, JPG and more), merge, split, rotate, protect and unlock PDFs, and turn Word, PowerPoint and Excel files into PDFs. All on your PC, and your originals are never changed. |
| **Screenshots** | ⌘⇧3 and ⌘⇧4 take screenshots the Mac way, saved with a Mac-style name and a thumbnail if you choose a folder. |
| **Trackpad** | Three-finger drag and ⌃-click for right-click. |
| **Remap any key** | Turn any key into another key, a shortcut, an app, a link or text, and write your own shortcuts for every app or just one. |
| **Extras** | Press-and-hold accents, text replacements, a ⌘-hold cheat sheet of shortcuts, and optional Mac key sounds. |

## Install in three steps

1. [Download Macify-win-Setup.exe](https://github.com/Cypherscamera/Macify-releases/releases/latest/download/Macify-win-Setup.exe) and run it.
2. A ⌘ icon appears in the system tray. Click it to open Macify, then follow the sign-in prompt with the license you got from [macify.finalcommit.dev](https://macify.finalcommit.dev/).
3. Use your keyboard like a Mac's. Hold ⌘ (the Alt key) on its own for a second to see every shortcut that works in the app you're in.

## Frequently asked questions

### What is Macify?
Macify is a Windows app that makes a Windows laptop's keyboard and touchpad behave like a Mac's. It adds ⌘ shortcuts, ⌘Tab app switching, Spotlight search, Quick Look, window tiling, a Dock, a menu bar, hot corners, a Control Center, voice dictation and file tools.

### How do I use Mac keyboard shortcuts on Windows?
Install Macify. The Alt key next to the spacebar becomes ⌘ Command, the Windows key becomes ⌥ Option and Ctrl becomes ⌃ Control. Most ⌘ shortcuts turn into the matching Ctrl shortcut (⌘C becomes Ctrl+C), and Mac-only ones like ⌘Tab, ⌘Space, ⌘⇧4 and ⌘Q are built in.

### Is there Spotlight search for Windows?
Yes. Press ⌘Space (Alt+Space) in Macify to search apps and files, calculate and search the web.

### Does Macify have voice dictation, and is it private?
Yes. Press ⌃⌥M, speak, and Macify types your words where the cursor is, in any app. It runs entirely on your PC, so your voice is never sent anywhere. You can also download a larger speech model in the app if you want more accuracy.

### Do I need administrator rights?
No. Macify installs and runs for your user account only.

### Which versions of Windows does Macify support?
Windows 10 (version 2004 or newer) and Windows 11, 64-bit.

### How do I get a Macify license?
Get a license at **[macify.finalcommit.dev](https://macify.finalcommit.dev/)**, then follow the sign-in prompt in Macify.

### How does Macify update?
Automatically. It checks for new versions every few hours and installs them when you choose Update and restart. Your settings and shortcuts are kept.

### How do I uninstall Macify?
Open Windows Settings, go to Apps, find Macify and choose Uninstall.

### Is Macify made by Apple?
No. Macify is an independent app and is not affiliated with or endorsed by Apple Inc. Mac, macOS, Spotlight, Dock and Quick Look are trademarks of Apple Inc., used here only to describe what Macify imitates.
