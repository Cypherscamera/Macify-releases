# Macify-releases
Installer and update files for Macify

## Download (Windows)

**[⬇ Download Macify-win-Setup.exe](https://github.com/Cypherscamera/Macify-releases/releases/latest/download/Macify-win-Setup.exe)**

Run the file and Macify installs itself. Future updates install automatically.

If Windows SmartScreen warns, click **More info → Run anyway**.
